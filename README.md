# Autonomia Digital 

Este site nasceu como um projeto de extensão universitária com um objetivo prático: democratizar o acesso à tecnologia e apoiar mulheres que querem resolver seus problemas digitais sem depender da ajuda de parceiros, amigos ou técnicos. 

A ideia é transformar conceitos que parecem difíceis em um passo a passo simples, direto e acolhedor.

## 💡 O que você encontra no site?

A plataforma foi pensada para ser direta ao ponto, dividida em três grandes guias de consulta rápida:

* **🛠️ Dicas Funcionais:** Para quando o computador começa a travar ou dar problemas de lentidão. Ensina a diagnosticar o que está acontecendo e resolver sem pânico.
* **🛒 Compre Sozinha:** Explica de forma simples o que significa memória RAM, processador e armazenamento, dando autonomia para escolher um notebook ideal sem cair em papo de vendedor.
* **🔒 Segurança Digital:** Focado em proteção real no dia a dia. Como proteger redes sociais, criar senhas fortes e identificar os golpes mais comuns da internet.

### 🤖 O Assistente de Compras
No canto da tela, integrei um assistente virtual interativo feito em JavaScript. Ele funciona através de uma árvore de decisão: você clica no seu objetivo (Estudar, Trabalhar, Jogar) e no seu orçamento, e ele recomenda na hora as melhores opções de computadores do mercado.

## 🛠️ Ferramentas Utilizadas

O projeto foi feito usando tecnologias web nativas para garantir que o site carregue rápido, mesmo em celulares mais antigos ou conexões fracas:

* **HTML5 & CSS3:** Estrutura e estilização personalizada com transições suaves e animações nativas.
* **Bootstrap 5:** Framework utilizado para garantir que o layout seja 100% responsivo (funciona bem em computadores, tablets e smartphones).
* **JavaScript Puro:** Toda a lógica de navegação rápida entre abas (Single Page Application), controle dos modais e o funcionamento do assistente virtual.
* **GitHub Pages:** Plataforma utilizada para a hospedagem gratuita do projeto.
